# PV Studio — المنصة الهندسية والاقتصادية لتصميم الأنظمة الكهروضوئية

تطبيق أولي بـ Streamlit يساعد على تقدير حجم نظام الطاقة الشمسية الكهروضوئي، وعدد الألواح، وقدرة العاكس، وسعة البطاريات، والمساحة المطلوبة، ثم إجراء تحليل اقتصادي مبسط يشمل فترة الاسترداد وNPV وLCOE والتدفقات النقدية والسيناريوهات.

## التشغيل محليًا

يتطلب Python 3.10 أو أحدث.

```bash
python -m venv .venv
```

تفعيل البيئة الافتراضية:

**Windows**
```bash
.venv\Scripts\activate
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

تثبيت المتطلبات وتشغيل التطبيق:

```bash
pip install -r requirements.txt
streamlit run solar_pv_app.py
```

سيفتح التطبيق في المتصفح. يمكن نشر المشروع على Streamlit Community Cloud من مستودع GitHub بعد رفع الملفات الثلاثة.

## المزايا

- واجهة عربية باتجاه RTL بتصميم متجاوب.
- مدخلات قابلة للتعديل للموقع، وساعات الذروة الشمسية، والاستهلاك، ونوع النظام، واللوح، والفواقد، والتخزين.
- مقارنة الأنظمة On-Grid وHybrid وOff-Grid.
- تقدير التكلفة، والصيانة والاستبدال، والتدفقات النقدية التراكمية، وNPV، وLCOE.
- سيناريو أساسي ومتفائل ومتحفظ.
- تصدير التقرير الفني والاقتصادي بصيغة Markdown والتدفقات النقدية بصيغة CSV.

## ملاحظات مهمة عن الدقة

هذا **نموذج أكاديمي مبسط** وليس أداة تصميم معتمدة للتنفيذ. لا يحاكي تغير الإشعاع والاستهلاك ساعة بساعة، ولا يحلل الظلال الفعلية، ولا يضمن تشغيل الأحمال في نظام Off-Grid. يجب إدخال بيانات مورد شمسي خاصة بالموقع، وتعرفة كهرباء صحيحة، وأسعار تركيب فعلية، وتعرفة تصدير فائض معتمدة إن وجدت. كما يجب تصميم قدرة العاكس والبطارية بناءً على الأحمال المتزامنة وتيارات بدء المحركات.
